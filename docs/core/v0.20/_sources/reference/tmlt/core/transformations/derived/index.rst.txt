.. py:class:: DerivedTransformation(wrapped_transformation)

   Bases: :class:`tmlt.core.transformations.base.Transformation`

   Base class for wrapping composite transformations.

   Subclassing :class:`.DerivedTransformation` allows the creation of new
   transformations that encapsulate a chain of existing components. These can
   be used to treat complex transformations as single units, rather than as an
   assembly of simpler components.

   Subclasses of :class:`.DerivedTransformation` must implement a constructor
   that builds a :class:`.Transformation` and passes it to
   ``super().__init__``. The execution and privacy properties of the subclass
   are delegated to that transformation. The subclass may define additional
   attributes or methods, but they do not affect its privacy properties; only
   the transformation passed to the :class:`.DerivedTransformation` constructor
   is considered.

   ..
       >>> from tmlt.core.domains.collections import DictDomain
       >>> from tmlt.core.domains.numpy_domains import NumpyIntegerDomain
       >>> from tmlt.core.metrics import AbsoluteDifference, DictMetric
       >>> from tmlt.core.transformations.identity import Identity
       >>> from tmlt.core.transformations.dictionary import GetValue

   .. rubric:: Example

   >>> class GetNestedValue(DerivedTransformation):
   ...     def __init__(self, input_domain, input_metric, keys):
   ...         xf = Identity(input_metric, input_domain)
   ...         for key in keys:
   ...             xf = xf | GetValue(xf.output_domain, xf.output_metric, key)
   ...         super().__init__(xf)
   >>> xf = GetNestedValue(
   ...     DictDomain({"a": DictDomain({"b": NumpyIntegerDomain()})}),
   ...     DictMetric({"a": DictMetric({"b": AbsoluteDifference()})}),
   ...     keys=("a","b"),
   ... )
   >>> xf.output_domain
   NumpyIntegerDomain()
   >>> xf({"a": {"b": 5}})
   5
